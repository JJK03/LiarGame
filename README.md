# 🎭 Liar Game

## 📌 프로젝트 소개
**Liar Game**은 TCP/IP 기반 **멀티플레이어 추리 게임**입니다.  
플레이어는 서로의 역할을 추리하며, **거짓말쟁이**를 찾아내야 합니다.

### 🔧 기술 스택
| 구분 | 기술 |
|------|------|
| 프론트엔드 | React |
| 백엔드 | Node.js (Express) |
| 데이터베이스 | MySQL |
| 네트워크 | TCP/IP 기반 소켓 통신 |

## 🌟 프로젝트 특징
- 실시간 TCP/IP 기반 멀티플레이어 게임  
- 직관적인 UX/UI 적용  
- React와 Node.js를 활용한 클라이언트-서버 통신
