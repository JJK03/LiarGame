# 🎭 Liar Game

## 📌 프로젝트 소개
**Liar Game**은 TCP/IP 기반 **멀티플레이어 추리 게임**입니다.  
플레이어는 서로의 역할을 추리하며, **거짓말쟁이**를 찾아내야 합니다.

## 🚩 기본 게임 흐름:
1. 사용자가 닉네임만 입력하고 입장
2. 방 목록에서 방 선택 또는 생성
3. 방에 입장하면 다른 플레이어들과 채팅
4. 게임 시작하면 한 명이 라이어로 선정
5. 제시어는 서버에서 랜덤 선택
6. 라이어는 제시어를 모름
7. 턴마다 돌아가면서 제시어 관련 설명
8. 채팅으로 토론
9. 투표로 라이어 지목
